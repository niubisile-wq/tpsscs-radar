# AISTAP Final Experiment Leverage Assessment

Date: 2026-07-13

## Question

Is there still one more AISTAP experiment that would materially improve the comparison position against the five-reference set before final submission lock?

## Assessment

No additional single experiment now looks likely to change the comparison position in a meaningful way.

The paper already has the pieces that matter for the five-reference comparison:

- a dense low-rank / CFAR operating surface,
- oracle target-preservation diagnostics,
- a minimal trainability check,
- a perturbation stress grid,
- and an explicit five-reference gap audit.

Those experiments cover the same comparison dimensions that the reference packages are strong on: evidence layering, boundary discipline, operating-policy detail, and bounded claim language.

## Why the leverage is low now

- A new experiment without a new dataset would mostly refine an already-measured frontier.
- A new experiment that remains on the public sample would still not create deployable detector closure.
- A new experiment that widens scope would weaken the manuscript boundary instead of strengthening it.

## Practical conclusion

The remaining work is final manuscript integration and claim tightening, not another expansion of the experiment set.

If the paper is to move beyond the current comparison position later, it will need either:

- a genuinely new data source, or
- a deployable target-preservation branch that changes the evidence class.

Neither of those is an incremental add-on at this stage.
