# Minimal reproducible structure

If a lighter archive is needed later, keep these paths:

- `manuscripts/`
- `scripts/`
- `src/`
- `logs/`
- `results/`
- `figures/main/`
- `claim_matrix.md`
- `STATUS.md`
- `README.md`
- `CITATION.cff`
- `.zenodo.json`

If storage must be reduced further, move large raw downloads out of the public repo and retain only:

- scripts
- derived results
- logs
- manuscript source
- figure-generation code
- dataset acquisition notes
