# Release v1.0.0

This release packages the repository state used for the first public archival bundle of the TP-SSCS radar detection project.

## Included

- Manuscript source and final submission package
- Experiment code and evaluation scripts
- Derived logs, figures, and summary tables
- Downloaded public dataset assets already present in the workspace
- Reproducibility and claim-audit notes

## Repository hygiene

- Large binary assets are tracked with Git LFS where applicable.
- Generated LaTeX auxiliary files remain ignored.
- The repository is intended as a reproducibility archive, not a minimal source-only library.
